# ML Notes

Notes and summaries written while studying machine learning papers. Each
entry captures the problem the paper tackles, the key idea, and whatever
math or code made it click.

## How this is organized

- **[Papers](papers/index.md)** — one page per paper, covering the
  problem it tackles, the key idea, and the architecture or method behind
  it.
- **[Concepts](concepts/index.md)** — one page per general ML/math
  concept that spans multiple papers, such as matrix factorization or
  backpropagation.

Browse either section from the navigation, or use search to jump straight
to a topic.
